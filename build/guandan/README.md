# 掼蛋（内嵌游戏）

本目录是阳鸽「掼蛋」入口加载的本地静态资源，不访问外网。

- 上游源码：<https://github.com/dengweiqh/guandan-windows>

## 本仓库内的修改

1. 移除 Trae 推广徽章插件及其外链点击目标。
2. 移除 Google Fonts 外链，改用系统字体栈。
3. 移除「多人联机大厅」入口（阳鸽当前只内置单机对 AI 模式）。
4. 构建目标固定为 Chrome 108（Electron 22 对应内核）。
5. 增加页面 CSP，并把构建输出中的 sourcemap 删除。

游戏逻辑、AI 与界面均来自上游；需要修改规则或联机时请回到上游源码，修改后重新构建 `dist` 覆盖本目录。

## 联机与积分（阳鸽改动）

- 房间服务由阳鸽主进程随应用启动，监听 `0.0.0.0:17890`；房主在本机建房，同事在游戏大厅填写房主地址或直接点在线同事加入。
- 服务器按席位记录玩家昵称，初始 1000 分；积分与排行榜保存在房主数据目录 `data/guandan-scores.json`。
- 计分规则：双下（1+2）赢家 +40 / 输家 −20；1+3 赢家 +30 / 输家 −15；1+4 赢家 +20 / 输家 −10；最低 0 分。
- 服务端代码由上游 `server/index.js` 增加昵称、积分与排行榜事件后打包为 `guandan-server/server.cjs`。

## 桌面背景（阳鸽改动）

- 内置「宣纸 / 远山 / 竹影 / 江波 / 梅枝」五套本地 SVG 背景，可在游戏「设置 → 桌面背景」切换。
- 支持上传 JPG/PNG/WebP，自动压缩到最长边 1600px（JPEG 0.82）后保存在本机 localStorage，不上传任何服务器；可一键恢复默认。
- 背景层上覆盖一层米色薄纱，保证牌面与座位信息可读。

## 头像与布局（阳鸽改动）

- 联机座位读取阳鸽资料：预设动物头像、首字头像、自定义头像（`pantry-avatar://`）与昵称按席位同步；AI 座位保留首字头像。
- 牌桌顶栏改为通栏，对家面板下移，上下家向中间收拢；队伍标签改为浅色系。
